# Lab 1: Trace Annotation

## Objective

Annotate failed traces from the Level 2 benchmark.

## Build

Select at least 20 failed tasks and annotate:

- first visible failure
- failure category
- evidence
- likely root cause
- possible intervention

## Deliverable

Submit annotated traces in JSONL or Markdown.

## Checks

The lab passes if every annotation cites evidence from the trace.
