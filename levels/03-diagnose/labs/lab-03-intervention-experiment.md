# Lab 3: Intervention Experiment

## Objective

Test one targeted fix.

## Build

Choose one dominant failure mode and design one intervention.

Examples:

- improve a tool schema
- add final answer validation
- change a retrieval query
- add a prompt instruction
- add an approval gate

## Deliverable

Submit:

- hypothesis
- intervention diff or description
- before and after benchmark scores
- conclusion

## Checks

The lab passes if the intervention is tied to a diagnosed failure mode.
