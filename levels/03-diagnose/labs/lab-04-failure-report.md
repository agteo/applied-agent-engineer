# Lab 4: Failure Report

## Objective

Write the first Agent Failure Report.

## Required Sections

1. Executive summary
2. Benchmark run analyzed
3. Failure taxonomy
4. Failure distribution
5. Representative failures
6. Tested intervention
7. Recommendation
8. Data needs for Level 4

## Deliverable

Submit a report that another engineer can use to plan the next improvement cycle.

## Checks

The lab passes if the report replaces vague model criticism with evidence-backed failure analysis.
