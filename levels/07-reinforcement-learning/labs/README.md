# Level 07: RL Literacy labs

| Lab | Objective |
| --- | --- |
| [Lab 1: MDP Framing](lab-01-mdp-framing.md) | Frame your environment as an MDP, concretely enough that someone else could implement a runner from your description — and find out whether your problem has that shape at all. |
| [Lab 2: Rollout Dataset](lab-02-rollout-dataset.md) | Produce a rollout log that answers questions about a run without re-running it, and a filter that has been seen to reject something. |
| [Lab 3: Reward Hacking Review](lab-03-reward-hacking-review.md) | Find your reward's exploits before a training run does, and name the one you cannot close. |
| [Lab 4: RL Experiment Report](lab-04-rl-experiment-report.md) | Write the report and the decision rule **before** any run, so a disappointing result can be published. |

Each lab links a reference artifact and states a check you can run or a
rubric you can apply. Write your own version first, then compare.
