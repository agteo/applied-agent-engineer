# Lesson 1: RL Framing

## Core Idea

Reinforcement learning frames behavior as interaction between an agent and an environment.

## Concepts

- state
- action
- observation
- reward
- policy
- episode
- return
- termination

## Acme Example

```text
State:
Employee trip, receipts, policy, draft status.

Action:
Request manager approval.

Reward:
Positive if approval was required and requested, negative if unnecessary or missing.
```

## Checkpoint

You are ready to move on when you can map an Acme task to state, action, reward, and termination.
