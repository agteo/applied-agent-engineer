# Lesson 5: Preference and Correction Data

## Core Idea

Failures can become demonstrations, corrections, or preference pairs.

## Data Shapes

Demonstration:

```text
task -> ideal answer
```

Correction:

```text
bad answer -> corrected answer
```

Preference:

```text
task + answer A + answer B -> preferred answer
```
