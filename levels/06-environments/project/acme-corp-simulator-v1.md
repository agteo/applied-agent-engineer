# Project: Acme Corp Simulator v1

## Objective

Build a simulated company environment where Acme Expense Agent can complete expense reimbursement tasks safely and reproducibly.

## Required Components

- environment state schema
- simulated tools
- task generator
- success checks
- reward function
- rollout logger
- environment manifest

## Required Tasks

Create at least 100 tasks covering:

- straightforward reimbursement
- missing receipts
- meal limits
- ambiguous receipt lookup
- manager approval
- unsafe submission attempts
- multi-step trip reimbursement
- edge cases

## Submission Checklist

- [ ] Environment state documented.
- [ ] Five or more simulated tools implemented or specified.
- [ ] 100+ tasks generated.
- [ ] Success checks implemented or specified.
- [ ] Reward function documented.
- [ ] Rollout format documented.
- [ ] Simulator bias note included.
