# Lab 2: Simulated Tools

## Objective

Build safe simulated tools for the environment.

## Required Tools

Implement at least five:

- `search_policy`
- `lookup_receipt`
- `get_employee_profile`
- `create_reimbursement_draft`
- `request_manager_approval`
- `submit_reimbursement`

## Deliverable

Submit:

- tool schemas
- transition behavior
- error cases
- example tool logs

## Checks

The lab passes if tool calls update state and produce inspectable observations.
