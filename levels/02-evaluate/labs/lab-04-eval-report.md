# Lab 4: Eval Report

## Objective

Turn benchmark results into a decision-ready report.

## Build

Compare two Acme Expense Agent configurations.

Examples:

- baseline prompt vs improved prompt
- one model vs another model
- keyword search vs improved search
- no approval gate vs approval gate

## Required Sections

Your report should include:

1. decision summary
2. benchmark description
3. agent versions compared
4. headline metrics
5. category-level slices
6. example successes
7. example failures
8. judge calibration summary
9. limitations
10. recommendation

## Deliverable

Submit:

- eval report
- raw score file
- benchmark run metadata
- recommendation

## Checks

The lab passes if the report makes a clear adopt, reject, or keep-testing recommendation.
