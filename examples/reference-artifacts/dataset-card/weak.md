# Weak Dataset Card: StrongBench Agent Training Dataset v1

This dataset contains examples for training the expense agent. It includes
traces, failures, and synthetic data. The data was cleaned and split into train,
dev, and test. It should improve the model because it covers the mistakes the
agent made.

## Why This Is Weak

This card gives no row counts, rejection reasons, source proportions, split
rules, provenance standard, or contamination warning. It also claims model
improvement without benchmark evidence.
