# Acme Expense Agent

This folder will contain the canonical course agent implementation.

The agent begins as a Level 1 tool-using assistant and evolves throughout the curriculum:

| Level | Agent Milestone |
| --- | --- |
| 1 | Basic tool-using expense assistant |
| 2 | Evaluated agent with benchmark reports |
| 3 | Diagnosed agent with failure taxonomy |
| 4 | Data-producing agent with curated traces |
| 5 | Agent backed by a fine-tuned or adapted model |
| 6 | Agent operating inside Acme Corp Simulator |
| 7 | Agent improved through experience and rewards |

Curriculum specs:

- [Level 1: Build](../../levels/01-build/README.md)
- [Level 2: Evaluate](../../levels/02-evaluate/README.md)
- [Level 3: Diagnose](../../levels/03-diagnose/README.md)
- [Level 4: Data and Feedback](../../levels/04-data/README.md)
- [Level 5: Post-training](../../levels/05-post-training/README.md)
- [Level 6: Environments](../../levels/06-environments/README.md)
- [Level 7: Reinforcement Learning](../../levels/07-reinforcement-learning/README.md)

Implementation should begin after the Level 1 docs are stable.
