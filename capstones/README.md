# Capstones

The course has two capstones.

The core capstone is required and does not require a GPU. The advanced capstone is optional and requires access to GPU compute.

## Capstone 1: Core Practical

Required for core completion.

Focus:

```text
Build -> Evaluate -> Diagnose -> Data Recommendation
```

Learners improve a flawed Acme Expense Agent, run a benchmark, diagnose failures, and recommend the next data or system intervention.

Start here: [core-practical/README.md](core-practical/README.md)

## Capstone 2: Advanced GPU Model Adaptation

Optional advanced capstone.

Focus:

```text
Curated data -> Local model adaptation -> Benchmark comparison -> Adoption decision
```

Learners use a GPU to run a small SFT or LoRA experiment, produce an adapter or checkpoint, evaluate it against the same benchmark, and decide whether the adapted local model should be adopted.

Start here: [advanced-gpu-model-adaptation/README.md](advanced-gpu-model-adaptation/README.md)

## Why Two Capstones?

The core course should not require GPU access. The most important applied skill is improving an AI system through evaluation, diagnosis, and data discipline.

The advanced capstone exists for learners who want to make the model-training claim honestly. It requires real compute, training logs, an artifact, and benchmark evidence.
