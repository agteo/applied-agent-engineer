# Project Status

This repository is currently a curriculum specification and course scaffold.

It is not yet a complete executable course.

## Current State

What exists:

- course framework
- syllabus
- mental models
- module outlines for Levels 1-7
- lesson, lab, and project specifications
- repo structure for examples, evals, datasets, and environments

What does not exist yet:

- runnable Acme Expense Agent implementation
- Acme policy and receipt fixtures
- 100-task golden benchmark
- grader implementations
- reference solutions
- automated checks
- dataset examples
- simulated environment implementation
- training scripts
- dependency file
- CI workflow

## Honest Claim

Today, this repo can help a curriculum author, instructor, or experienced engineer understand the intended course architecture.

It cannot yet reliably level up a solo learner without additional implementation, fixtures, reference solutions, and feedback mechanisms.

## Near-Term Definition of Done

The first usable release should support Levels 1-2 end to end:

1. Learner can run Acme Expense Agent v1 locally.
2. Learner can run the Level 1 labs.
3. Learner can compare their work against reference solutions.
4. Learner can run a 100-task benchmark.
5. Learner can see automated pass/fail checks and grader feedback.
6. Learner can produce an eval report from real benchmark output.

Until those are true, the repo should be described as a specification under active construction.
