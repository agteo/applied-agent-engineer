# Acme Agent Training Dataset v1

## Intended Use

Use this dataset to prototype supervised correction, preference, and regression-data workflows for the Acme Expense Agent. It is a teaching dataset, not production financial data.

## Sources

- Level 1 trace demonstrations from `examples/acme-expense-agent/traces/level-1.jsonl`.
- Level 3 annotated benchmark failures from `evals/operations/acme/annotated-failures.jsonl`.
- Synthetic gap-targeted examples generated by `python3 -m datasets.acme`.

## Schema

Rows follow `datasets/acme/schema.json` and include `example_id`, `source_type`, `messages`, `target_final_answer`, labels, provenance, quality flags, and split.

## Cleaning

Rows without prompts, provenance, or contract-shaped targets are rejected. Duplicate prompt/target/source triples are removed.

## Metrics

- raw rows: 155
- cleaned rows: 152
- rejected rows: 3
- splits: {"dev": 47, "heldout": 27, "train": 78}
- sources: {"failure_correction": 30, "level1_trace": 22, "synthetic_gap_target": 100}

## Limitations

Synthetic examples are template-generated and should not be used to claim real model improvement without held-out benchmark evaluation. Correction targets are compact oracle summaries, not full human-authored ideal answers.

## Privacy

All examples use fictional Acme fixtures. No personal, customer, or production data is included.

## Level 5 Use Case

Use the train split for small SFT experiments, the dev split for prompt or adapter iteration, and the heldout split plus the Level 2 benchmark for regression checks.
