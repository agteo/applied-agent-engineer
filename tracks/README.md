# Specialization Tracks

Levels 1-4 are the common core. After that, learners can specialize without treating Level 7 as the only valid endpoint.

```text
Common Core
  L1 Agent & Harness Engineering
  L2 Evaluation
  L3 Production Eval Operations and Failure Analysis
  L4 Data & Feedback

Specializations
  Agent Quality Engineering
  Model Improvement
  Environment and Verifier Engineering
  RL for Agent Reliability
```

The tracks are career architectures, not separate disconnected courses. They all reuse the same artifacts: traces, eval datasets, failure reports, curated data, simulator tasks, verifiers, and benchmark reports.

| Track | Primary Outcome |
| --- | --- |
| [Agent Quality Engineering](agent-quality-engineering.md) | Operate evals, observability, regression checks, and release gates for production agents. |
| [Model Improvement](model-improvement.md) | Decide when and how to improve models with curated data, SFT, LoRA, DPO, or better system design. |
| [Environment and Verifier Engineering](environment-verifier-engineering.md) | Build simulated workflows and hard success checks that can power evals and rewards. |
| [RL for Agent Reliability](rl-for-agent-reliability.md) | Turn verifier-derived rewards into rollout analysis and optional training experiments. |
